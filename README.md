# Irregardless — The Word You'd Delete From the Dictionary

An entry for make.fun's **The Word You'd Delete From the Dictionary** competition: name the one word to erase from the dictionary forever.

## The word

**irregardless** — the word that argues it isn't a word. It bolts a negative prefix (*ir-*) onto a word that already ends in a negative suffix (*-less*), so it cancels itself out before it even starts, and yet people keep saying it anyway. Delete it and nothing is lost: "regardless" was standing right there the whole time, doing the job properly.

## How it works

`main.py` (Python 3, standard library only) writes the entry word to `/output/entry.txt` — one word, 12 characters, inside the 1–77 character gate, with no trailing newline.

## Run it

```sh
python3 main.py
```
